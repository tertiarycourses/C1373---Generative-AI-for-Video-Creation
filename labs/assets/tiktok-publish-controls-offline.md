# TikTok Publish Controls — Offline Practice Simulation

Use this file only when the learner cannot log in or reach the upload screen. It mirrors the decisions that must be recorded in `07-publish-and-repurpose-pack.md`; it does not publish anything.

## Simulation Instructions

1. Open the final MP4, edit-quality log, asset register, and publish pack.
2. The learner reads each control below aloud and states the chosen value.
3. The trainer checks the source evidence and records their name plus date/time in the publish pack.
4. Mark the evidence `OFFLINE SIMULATION`. Do not claim that an account upload was completed.

## Controls to Simulate

| Current decision area | Learner records |
|---|---|
| Upload identity | Exact MP4 filename, duration, dimensions, and version |
| Cover | Reviewed cover line and frame |
| Description | Final two-sentence description |
| Hashtags | Three to five subject-relevant tags |
| Audience | `Only you` for practice, or the approved external audience |
| Comments | On or off with reason |

| Commercial-content disclosure | Required state for brand, product, or service promotion |
| AI-generated-content setting | Required state based on realistic or significant AI generation/editing |
| Copyright check | Completed, unavailable offline, or blocked |
| Approval | Named account owner or `PRIVATE PRACTICE ONLY` |
